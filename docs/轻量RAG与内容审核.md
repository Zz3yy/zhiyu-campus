# 轻量 RAG 与内容审核

## 目前实现

知识库包含现有 19 个行动（15 个自助活动与 4 个复习启动行动）和 2 条认知/复习引导，共 21 条。正文、来源、适用边界、版本和 SHA-256 内容指纹由 `KnowledgeBase` 登记。来源链接是参考资料，不代表机构审核、授权背书或逐字摘录。

**当前全部待审阅，没有虚构人工审核记录。** `knowledge/reviews.json` 默认为空。待审阅条目可作为原有目录草稿展示来源，但不进入 RAG 生成上下文。推荐阶段缺少审核过的适用依据时，直接使用已有固定本地引导，并明确标注草稿和未调用豆包。澄清阶段可继续对话；无检索依据时不得提供认知练习。

## 检索与生成流程

1. 服务端先验证匿名会话、风险表达及资料共享授权。
2. 从用户本轮主动输入生成本地 256 维字符二元组哈希向量。查询及其向量不落库，不请求额外云端服务。
3. 将审核状态、内容指纹和本轮行动策略作为过滤条件。数据库模式用 pgvector `<=>` 进行余弦距离精确排序，最多取 3 条、相似度至少 0.12；内存模式做相同向量运算并标注 `memory-vector`。
4. 将本轮已审核条目及其 ID 作为上下文交给豆包。推荐必须成功检索候选，再提出候选范围内的行动；不能只靠 `tool_choice=required` 判断执行成功。
5. 模型输出 `citationIds`，服务端只接受本轮检索返回的 ID，推荐必须引用对应行动条目。界面引用内容、链接、状态均来自服务端登记，不能让模型生成来源标签。
6. 用户点击确认后才创建任务。危险表达进入固定求助流程；未命中、检索失败或引用不匹配时明确降级，不显示伪造引用。

这是**词面向量检索基线**，不是神经语义 embedding。哈希会有碰撞，不擅长同义词，0.12 阈值尚未经过真实用户相关性评测。21 条的小库先采用精确检索，无需 HNSW。后续引入中文语义 embedding 时必须更改模型版本、维数和重建全库，不能混用向量。

“已引用”表示结构化来源 ID 通过校验，不意味着程序能证明自然语言每句话均被来源支持。还需人工评测生成忠实度、越界建议和召回质量。当前不宣称已实现 MCP 或多模态。

## 人工审核步骤

内容正文与来源清单见 [内容审核清单](内容审核清单.md)。审核人逐条打开参考资料，核对改写是否准确、时长和方法是否被适当限定、是否适合考试压力场景。不把程序测试通过当作人工或专业审核。

在已登录匿名花园的会话中，`GET /api/garden/chat/knowledge` 可读取公共条目状态；`GET /api/garden/chat/knowledge/review` 可读取正文与内容指纹。这两个端点只读，不允许浏览器修改审核状态。

对实际审阅通过的条目，在 `zhiyu-server/src/main/resources/knowledge/reviews.json` 添加记录：

```json
[
  {
    "id": "activity-exam_open",
    "contentHash": "从审核端点复制该版本的完整指纹",
    "reviewer": "实际审核人署名",
    "reviewedAt": "YYYY-MM-DD"
  }
]
```

以上是格式说明，不是有效审核记录。审核日期必须有效且不晚于当前日期。提交审核记录后重启后端。正文、来源、边界或版本变化会导致指纹不匹配，旧审核自动失效。移除记录后该内容不再进入检索，数据库索引在服务重启后的首次检索同步状态。严禁让模型自行写入批准记录。

## 数据库与启动

V3 迁移创建 `vector` 扩展及 `garden_knowledge_documents` 表。Compose 已使用 `pgvector/pgvector:pg16`，不需要更换镜像；已有普通 PostgreSQL 实例必须先安装扩展且迁移账号有创建扩展权限。迁移失败应修复环境，不能伪装成已启用 pgvector。

数据库模式第一次检索时同步公共知识条目和索引。表内不存储用户问题、花园记录或聊天正文。检索只使用当前代码登记且当前审核有效的条目，旧目录残留行不参与检索。

内存模式无需 PostgreSQL，适合交互测试，但不算 pgvector 验收。数据库异常返回 `UNAVAILABLE`；没有审核内容返回 `NO_APPROVED_CONTENT`；未命中返回 `NO_MATCH`。

## 验收

- 后端覆盖审核指纹失效、待审阅拦截、向量检索、候选范围、数据库异常、伪造引用、确认建任务。
- `KnowledgePostgresTest` 仅在 `ZHIYU_PGVECTOR_TEST_URL` 指向**一次性测试库**时运行，执行 Flyway、真实余弦查询与撤销审核验证。测试使用合成审核署名，不改生产审核清单。
- Playwright `knowledge.spec.ts` 检查来源标签、待审阅状态与移动端布局；完整测试需运行本次后端代码。
- 真实豆包与已审核生产知识库的联合验证，必须等人工审核完成后进行。不得为了演示自动标记审核通过。

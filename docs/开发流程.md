# 知愈校园工程化开发流程

## 迭代节奏

每个功能按照以下顺序推进：

1. 明确用户故事和验收标准。
2. 设计页面、数据结构和 API。
3. 编写数据库迁移和接口契约。
4. 完成前后端实现。
5. 编写单元测试和接口测试。
6. 在本地 Docker 环境验证。
7. 更新开发文档和变更记录。

## 分支约定

```text
main       可交付稳定版本
develop    日常集成分支
feature/*  单个功能分支
fix/*      缺陷修复分支
```

## 提交约定

```text
feat: 新增情绪记录接口
fix: 修复任务完成状态异常
test: 增加风险分层测试
docs: 更新接口文档
chore: 更新本地开发配置
```

## 质量门禁

- 前端构建通过。
- Spring Boot 测试通过。
- FastAPI 测试通过。
- 数据库迁移可重复执行。
- 敏感内容不写入普通日志。
- 任何高风险流程必须有安全降级路径。

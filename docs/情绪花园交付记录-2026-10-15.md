# 情绪花园第一轮交付记录

日期：2026-10-15。范围：参赛计划中的非 AI 核心闭环与原创花园视觉。完整参赛版本尚未完成。

## 已实现

- 原创 SVG 花园场景、树屋、六种植物，以及有头身手脚、园丁帽和服装的守园人物。人物包含欢迎、倾听、照顾、鼓励状态。
- 五个栏目：我的花园、播种情绪、树屋倾诉、任务簿、成长报告。手机采用底部导航。
- 阅读说明并同意后才创建匿名花园。随机 256 位 Bearer 凭证，数据库只保存 SHA-256 哈希，接口不接受自报用户编号。
- 同日多次播种、保存后动画、失败保留输入、请求键去重、点击回看。
- 可选 CBT 思维记录：情境、自动想法、支持/不支持的事实、更平衡的理解。
- 15 条校园微行动草案，每种情绪默认推荐两条，可换组、加入任务、完成、跳过、填写可选帮助度。
- 植物按完成任务和复盘成长，重复完成不会重复增加。缺席与低落不会造成枯萎。
- 依据播种时区判断次日复盘；允许好些、相同、更难受或暂不评价。保存自评强度变化。
- 七天报告：真实植物数量和占比、记录日期数、按实际完成时间统计的行动数、复盘记录。
- 三日晨露与七日装饰；当前奖励由仍保留记录中的最长连续天数计算，删除记录后可能失去奖励，尚未实现独立永久解锁记录。
- 两分钟呼吸引导，吸气约 4 秒、呼气约 6 秒，不要求屏息，可暂停退出。
- 求助入口、中国大陆紧急电话、适用地区与无真人值班说明。关键词只触发提示，不能可靠识别风险。
- 树屋固定自助引导、快捷场景、仅页面内存消息；页面明确注明未接 AI。
- 单株删除联动删除相关日记与任务；全部删除会撤销当前花园凭证。

## 数据实现与原计划的差异

新增 `garden_spaces` 表，将每个匿名花园保存为一个 JSON 文本聚合，并用数据库行锁串行更新，避免并发覆盖。当前容量上限为每花园 1000 条播种、2000 个任务。采用该结构是为本轮先交付可运行闭环；尚未按任务书拆分 emotion_entries/thought_records/reflections 等关系表。后续复杂查询、独立奖励或规模增长时应迁移。

旧每日记录和旧表未删除，但新界面尚不展示旧记录。旧版 MvpController 默认关闭，避免 X-User-Id 入口继续暴露。`memory` 模式使用隔离的内存实现，并在页面明确提示重启会清空。正常预览使用 PostgreSQL。

## 验证证据

- Java 21 下 Maven 测试：10 项通过，其中 6 项花园领域测试、2 项 HTTP 测试、2 项原有测试。
- 覆盖同日多株、重复播种、匿名会话隔离、跨用户写入拒绝、重复任务/完成、北京时间跨零点复盘、负向复盘、删除级联、撤销会话、无效同意与评分、禁用旧入口。
- Playwright + 本机 Edge：2 条端到端用例通过，使用真实后端和 PostgreSQL。覆盖同意、播种断网重试、日记、任务完成、刷新恢复、报告、树屋离开后清空、390px 手机无横向溢出、隐私入口与全部删除。
- 前端 TypeScript + Vite 生产构建通过。依赖版本已固定；安装 Playwright 时 Vite、lucide-react 和 React 插件随原有 latest 约束升级，最终使用版本已写入 package.json 和锁文件。
- PostgreSQL 16 中 Flyway V2 成功执行；重启后迁移校验通过，专用合成花园的记录 ID 恢复一致，随后清理了该专用测试花园。
- 已检查桌面/手机截图，截图由浏览器测试输出到忽略目录 `zhiyu-web/test-results/`。
- 原 FastAPI 未改动，本轮没有重跑其测试；此前两项测试通过不代表新的花园风险能力已验证。

## 已知限制与下一轮

1. 真实 AI、多轮上下文、服务端风险处理、结构化推荐、摘记均未接入。当前固定回复不能作为 AI 演示。
2. 活动和引导内容是草案，链接用于方法参考，尚未经专业人员逐项审核，也不证明治疗效果。
3. 关键词提示存在漏报和误报；校园资源尚未配置，禁止对外宣称提供自动危机识别或人工接管。
4. 悄悄话云端策略、账号恢复、HTTPS、限流及公开部署加固未完成。清除浏览器凭证后目前无法恢复匿名花园访问。
5. 角色与植物为原创代码矢量草图，还可继续打磨；未复制第三方产品，也未使用图像生成模型。
6. 已读取 REA 官方技能，当前没有明确的第三方参考页目标，未安装 REA、未声称完成网页逆向。后续选择具体页面和组件后按其工作流分析。
7. 七日奖励独立持久化、旧记录展示、月报告和精细化艺术设计留待下一轮。
8. 本轮改动未自动提交 Git；仓库原本尚无提交。

下一轮优先补模型服务接入及同意机制，再做三个风险场景与内容审阅，最后打磨参赛视频和材料。

# 内容审核入口

本库当前 **150 条已审核**。JSON 已作为程序和审核的正式数据格式，Markdown 仅说明流程。

- 正文与元数据：[corpus.json](../zhiyu-server/src/main/resources/knowledge/corpus.json)
- 来源核验程度：[sources.json](../zhiyu-server/src/main/resources/knowledge/sources.json)
- 逐条审核工作表：[knowledge-review.json](knowledge-review.json)，包含完整正文、来源关系、指纹、四项核对结果、审核人和日期。
- 实际批准清单：[reviews.json](../zhiyu-server/src/main/resources/knowledge/reviews.json)，150 条均已记录审核指纹、审核人和日期。

| 类别 | 数量 | 审阅重点 |
| --- | ---: | --- |
| 行动 | 19 | 与现有行动目录一致、时长与停止边界 |
| 原理与边界 | 45 | 理论说明是否忠于来源，是否混入未经支持的效果结论 |
| 校园场景 | 43 | 是否贴合备考、是否清楚标为项目自拟案例 |
| 引导模板 | 43 | 是否自愿、是否诱发额外负担或暗含诊断、是否需要较高认知负荷 |

每条已由 Zz3 核对四项：出处可验证、改写与来源关系准确、安全边界合适、元数据恰当。NHS/WHO 的资料入口可访问和 DOI 核验；审核通过表示内容可进入本项目的受限检索，不代表适用于每个用户或具有临床疗效证据。

后续修改正文、来源、边界或元数据会改变 `contentHash`，旧批准将自动失效；未通过或需要修改的条目应从批准清单移除。Markdown 勾选、JSON 工作表的 `checks` 与 `reviewStatus` 仅是审核记录，运行时以 `reviews.json` 的指纹匹配为准。

审核记录按 150 条分别绑定内容指纹；批量写入是对 Zz3 已完成逐条审阅结果的登记，不是模型审批或自动批准。之后可进行真实豆包联合验收。

更新正文后运行 `python scripts/knowledge-review.py --export` 可重新导出，但会覆盖工作表中的手工勾选；先保存已有审核记录。新指纹与旧批准不匹配时，条目自动失去检索资格。更多细节见 [检索与审核实现](轻量RAG与内容审核.md)。

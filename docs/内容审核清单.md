# 内容审核入口

本库当前 **150 条待审阅**。JSON 已作为程序和审核的正式数据格式，Markdown 仅说明流程。

- 正文与元数据：[corpus.json](../zhiyu-server/src/main/resources/knowledge/corpus.json)
- 来源核验程度：[sources.json](../zhiyu-server/src/main/resources/knowledge/sources.json)
- 逐条审核工作表：[knowledge-review.json](knowledge-review.json)，包含完整正文、来源关系、指纹、四项核对项及空白署名/日期。
- 实际批准清单：[reviews.json](../zhiyu-server/src/main/resources/knowledge/reviews.json)，当前为空。

| 类别 | 数量 | 审阅重点 |
| --- | ---: | --- |
| 行动 | 19 | 与现有行动目录一致、时长与停止边界 |
| 原理与边界 | 45 | 理论说明是否忠于来源，是否混入未经支持的效果结论 |
| 校园场景 | 43 | 是否贴合备考、是否清楚标为项目自拟案例 |
| 引导模板 | 43 | 是否自愿、是否诱发额外负担或暗含诊断、是否需要较高认知负荷 |

每条需要真人核对四项：出处可验证、改写与来源关系准确、安全边界合适、元数据恰当。NHS/WHO 的资料入口可访问和 DOI 核验，不代表 150 条改写已经人工审核或适用于每个用户。

通过后，把对应的 `id`、`contentHash`、实际 `reviewer` 与 `reviewedAt` 填入生产批准清单，日期用 `YYYY-MM-DD`；未通过、未核对或需要修改的条目保持待审。Markdown 勾选、JSON 工作表的 `checks` 与 `reviewStatus` **不会自动改变运行时审核状态**。

可先审核四个复习行动 `activity-exam_open / exam_outline / exam_paragraph / exam_question`，以及执行意图、自我关怀、降低负担的概念/案例，再进行真实模型验收。批准权不交给模型，也不一次性伪造批量审核。

更新正文后运行 `python scripts/knowledge-review.py --export` 可重新导出，但会覆盖工作表中的手工勾选；先保存已有审核记录。新指纹与旧批准不匹配时，条目自动失去检索资格。更多细节见 [检索与审核实现](轻量RAG与内容审核.md)。

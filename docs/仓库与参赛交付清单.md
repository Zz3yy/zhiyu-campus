# 仓库与参赛交付清单

## 历史说明

本仓库于 2026-10-26 将已有项目导入 Git，首次提交为当前代码的基线快照。
导入前的开发未包含在 Git 提交历史中；已有日期的开发文档仅作为过程记录，不等同于 Git 历史。
后续按真实开发过程提交，不回填提交日期、不伪造早期提交。

## 提交范围

保留源码、测试、依赖清单与锁文件、环境变量示例和项目文档。
忽略依赖及依赖备份、构建产物、测试输出、真实 .env 配置和 IDE 文件。
Git 作者邮箱将随提交记录保留；发布远端前应确认可以公开。

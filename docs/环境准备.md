# 环境准备

本文件为快速索引，当前完整配置以 [环境与运行说明](environment.md) 和仓库根目录 [README](../README.md) 为准。

## 必需工具

- Git
- JDK 21
- Maven 3.9+
- Node.js 22.12+（建议 Node 24 LTS）
- pnpm 12.4.2（与当前前端锁文件匹配）

本地内存演示无需 Docker、Python 或模型凭证。数据库模式需 Docker Compose；真实豆包联调需由开发者在后端进程中安全配置方舟环境变量。独立 FastAPI 目录是预留服务，不是当前树屋主流程依赖。

## 初始化检查

在仓库根目录按 README 的命令启动内存后端和前端。前端安装依赖时使用冻结锁文件：

```sh
pnpm --dir zhiyu-web install --frozen-lockfile
pnpm --dir zhiyu-web build
mvn -f zhiyu-server/pom.xml -B test
```

数据库模式、E2E、环境变量以及开发者原有 D 盘工具链说明见 [environment.md](environment.md)。不要把真实凭证写入 `.env.example`、前端 `VITE_*` 变量、代码、提交记录或录屏。

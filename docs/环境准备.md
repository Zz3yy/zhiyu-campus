# 环境准备

## 必需环境

- Java 21
- Maven 3.9+
- Node.js 20+
- pnpm 11+
- Python 3.12+
- Docker Desktop

## 验证命令

```bash
java -version
mvn -version
node --version
pnpm --version
python --version
docker --version
```

## 初始化步骤

```bash
cd zhiyu-web
pnpm install
pnpm build

cd ../zhiyu-ai-service
python -m pip install -r requirements.txt
python -m pytest -q

cd ../deploy
docker compose up -d postgres redis
```

Spring Boot 需要使用 Java 21 和 Maven 3.9+ 启动；当前模板没有将 Maven Wrapper 提交进仓库，后续可以在安装 Maven 后执行 `mvn wrapper:wrapper` 固化版本。
